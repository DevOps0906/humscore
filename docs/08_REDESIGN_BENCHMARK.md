## 공통 패턴 5개
1. 히어로 한 줄은 "입력 → 출력" 구조이고 CTA는 "무료로 시작" 계열 하나(Songscription·Klangio·Noteflight·Flat).
2. 결과 예시를 랜딩 상단~중단에 보여 준다(예시 카드, 원본/결과 비교, 샘플 곡 캐러셀).
3. 사회적 증거 + 끝부분 FAQ + 반복되는 하단 CTA 순서(Songscription·Flat 후기→FAQ→CTA).
4. 대시보드는 "검색 + 정렬 + 우상단 새로 만들기" 기본형, 폴더는 1단계 컬렉션(Klangio·Flat·Noteflight).
5. 모바일은 계정 동기화로 같은 목록을 연다(Klangio Songbook·Flat 동기화 섹션).
(주의: 최근 구분·빈 상태 문구는 조사한 곳 어디서도 확인하지 못해 패턴으로 말할 수 없다.)

## HumScore 차별점을 살릴 제안 3개
1. **히어로를 "지금 흥얼거려 보기" 한 버튼으로**: 업로드·링크·파일 선택지가 없는 경쟁 대비 가입 전 15초 체험. 버튼 아래 한 줄 "마이크 소리는 이 기기 밖으로 나가지 않아요(음표 숫자만 저장)". 경쟁 히어로에서 이 약속은 확인되지 않았다.
2. **랜딩 3단계 + 실제 결과 데모**: "흥얼 → 악보 → 재생" 3단계(Klangio 구조) 바로 아래에 샘플 허밍 재생과 생성된 악보 비교(원본/결과). 후기·사용자 수는 확보 전까지 넣지 않는다(미확인 수치 금지).
3. **/library를 "허밍 시작" 중심으로**: 우상단 고정 "악보 만들기"(모바일은 상단 아이콘+하단 큰 마이크 버튼), 검색+정렬 한 줄, 1단계 폴더, 빈 상태는 "허밍 시작" 버튼과 개인정보 문구, 삭제는 30일 복구 보관함.

## 6. Klangio 메인(klang.io/ko) 상세 — 랜딩 v2 기준 (2026-10-28, 사용자 지시)
- 출처: https://klang.io/ko/ 실측(1280·375 캡처). 구조·동작만 차용, 문구·이미지·로고·브랜드는 쓰지 않는다.
- **히어로(거의 동일 구조로)**: 반투명 고정 헤더 → 좌측 텍스트(작은 h1 "카테고리" + 굵은 h2 가치 문장 + 형식 나열 부제 + 외곽선 버튼 1개 "작동 방식"→사용법 앵커, 페이드인) / 우측 노트북+휴대폰 기기 목업(악보 화면·악보 목록 화면). 배경: 어두운 바탕에 흐르는 오선 곡선 + 떠다니는 음표·높은음자리표(청록 글로우) + 흐릿한 보케 원. 하단 신뢰 띠 5칸(세로 구분선, 순차 fade-up). 모바일: 가운데 정렬, 목업 숨김, 신뢰 띠 세로 나열.
- **섹션 순서**: 히어로 → 3단계(일러스트 3개를 진행선으로 잇고 큰 번호 1.2.3.) → 체험 띠("직접 경험해보세요"+CTA) → 통합 도구 2단(이미지+텍스트) → 입력별 앱 카드 그리드 → 숫자 띠 → 기타 도구 카드 3 → 후기 캐러셀 → 주요 기능 1~4단계 블록(블록마다 CTA) → 호환 도구 → 장점 6 그리드 → 언론 → 대상별 링크 5 → FAQ 13 → 푸터.
- **동작**: 스크롤 진입 시 요소별 fadeIn/fadeInUp(빠름), 기능 데모 영상 자동 재생, 후기 캐러셀, FAQ 아코디언, 헤더 드롭다운.
- **HumScore 대응 결정**: 후기·언론·근거 없는 수치 섹션은 자리만(숨김). 기능은 브라우저 처리 가능 범위만 추가 — 오디오 파일 업로드 채보, 피아노 롤, 기타 TAB(모두 단선율). 키 자동 추정은 이미 있음(`estimateKey`). 다성·YouTube·악보 스캔 제외.
