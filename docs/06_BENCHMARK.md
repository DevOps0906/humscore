# 06. 피아노 교육 앱 벤치마킹

> 목적: HumScore와 기획이 겹치는 부분(마이크 인식·실시간 피드백·악보 표시·건반 UI·진도·요금)을 경쟁 앱과 비교해 추가 기능 후보를 뽑는다.
> 원칙: 공식 스토어 페이지에서 확인한 사실만 쓰고 출처 URL을 단다. 확인하지 못한 것은 "미확인", 추측은 "추정"으로 표시한다.

## 3. HumScore와 겹치는 기획 부분별 시사점

### 3.1 마이크 인식
- 경쟁 앱 4곳 중 3곳(Simply·flowkey·Yousician)이 마이크 입력을 내세운다. 모두 "이미 있는 악보를 따라 친 음이 맞는지" 판정하는 용도다(추정: 정답 악보가 있으므로 판정이 쉬움).
- HumScore는 정답 없이 흥얼거림을 악보로 만든다. 같은 마이크 기술이지만 문제가 더 어렵다. 경쟁 앱은 마이크 외에 MIDI/블루투스 경로를 따로 제공한다(flowkey, 피아노스쿨).
- 시사점: 마이크가 불안정한 환경(소음, 빠른 패시지)을 위해 **88건반 입력이 이미 안전 경로**임을 화면에서 분명히 드러낸다. 피치 추적의 빠른 패시지 한계(최소 음 길이 0.09초, 16분음표 격자)는 템포 안내·느린 속도 녹음 권장 문구로 흡수한다.

### 3.2 실시간 피드백
- flowkey의 Wait Mode와 Just Play는 "초보자는 박자를 놓쳐도 진행이 막히지 않게"라는 두 모드를 분리한다. Yousician은 점수·별로 동기를 준다.
- 시사점: HumScore는 학습 앱이 아니므로 점수화는 핵심이 아니다. 다만 **저장한 악보를 따라 칠 때(공연 모드 확장) Wait 방식**은 비용 대비 효과가 클 수 있다(추정).

### 3.3 악보 표시
- flowkey는 영상과 악보·건반 강조를 한 화면에 묶는다. Simply Piano는 속도 조절을 기본 기능으로 둔다.
- 시사점: HumScore의 공연 모드에 **재생 속도 조절**과 **현재 음 강조**가 있는지 점검한다. 구간 반복은 연습에 필수 기능으로 보인다.

### 3.4 건반 UI · 화면 방향
- 피아노스쿨은 가로 지원을 버전 기록에 명시한다. flowkey는 태블릿 악보 연습에서 세로를 안내한다. 즉 업계 합의가 없다.
- 시사점: HumScore의 "모바일·태블릿 가로 고정 + C4 중심 2옥타브 이상"은 건반 폭 확보 측면에서 타당하다. 악보 영역 높이가 줄어드는 단점이 있으니 가로에서 악보/건반 분할 비율을 사용자 테스트로 정한다.
- Simply Piano의 "화면 건반 코스"는 실제 피아노가 없는 사용자도 고려한 선례다. HumScore의 88건반 입력과 같은 방향이다.

### 3.5 학습 진도
- 경쟁 앱은 모두 커리큘럼과 잠금 해제 구조를 가진다. HumScore는 커리큘럼이 없다.
- 시사점: 커리큘럼을 만드는 것은 범위 밖이다. 대신 "내 악보 보관" 안에서 **최근 연습·즐겨찾기·연습 횟수** 정도의 가벼운 기록을 검토한다.

### 3.6 요금
- 월 $19.99, 연 $119.99 구간이 Simply Piano·Yousician에서 동일하게 보인다. 국내 피아노스쿨은 1년 239,000원, 1개월 40,000원이다.
- 시사점: 무료 범위(녹음→악보 변환 횟수)와 유료 범위(내보내기, 클라우드 보관)를 먼저 나누고 가격은 이 문서에서 정하지 않는다.

- 상 우선순위 3건은 기존 `Score`·오디오 코어를 크게 바꾸지 않는다.

## 5. 차별화 포인트

1. **흥얼거림 → 악보**: 조사한 4개 앱 모두 설명에서 "정답 악보를 따라 치는" 흐름이다. 사용자가 만든 선율을 악보로 만드는 설명은 확인하지 못했다(범위: 스토어 설명 기준).
2. **창작·보관 중심**: 곡을 배우는 도구가 아니라 내 곡을 기록·전조·출력하는 도구. 커리큘럼 경쟁을 피한다.
3. **전조·셈여림·도돌이표**: 스토어 설명에서 이 편집 기능은 확인되지 않았다.
4. **웹+iOS+Android 한 코드베이스**: 설치 없이 웹에서 바로 시작할 수 있다. 경쟁 앱 4곳은 스토어 페이지 기준 모바일 앱 중심이다(웹 제공 여부는 미확인).
5. **마이크 + 건반 이중 입력**: 마이크가 어려운 환경에서도 같은 결과물에 도달한다.
6. **음성 비저장**: 음표 숫자만 유지한다(개인정보 부담이 낮음). 경쟁 앱 처리 방식은 미확인이므로 비교 문구로 쓰지 않는다.

## 6. 하지 않을 것

- 타사 화면 레이아웃, 아이콘, 일러스트, 문구, 곡 목록, 영상, 로고, 앱 이름 유사 표기를 복제하지 않는다. 기능 아이디어만 참고하고 모두 새로 만든다.
- 스토어 스크린샷·설명문을 저장소나 앱에 넣지 않는다.
- 저작권이 있는 곡을 라이선스 없이 번들하지 않는다(라이브러리 기능은 권리 확인 후).
- 경쟁 앱을 "정확도가 낮다" 식으로 근거 없이 비교하는 문구를 쓰지 않는다.
- 커리큘럼·잠금 해제·점수 경쟁 같은 학습 앱 구조는 이번 범위에서 만들지 않는다.
- 이 문서의 가격·기능은 2026-10-28 스토어 표기이므로 마케팅 문구에 인용하기 전에 다시 확인한다.
