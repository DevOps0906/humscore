# ADR 0001. 유튜브 링크 → 악보: 사용자 탭 캡처 방식

상태: 제안(공개 전 법률 검토 필요) · 날짜 2026-10-28

## 맥락
경쟁 서비스는 유튜브 링크 입력을 지원한다([07_COMPETITORS.md](../07_COMPETITORS.md)#3). HumScore 원칙은 오디오를 저장·전송하지 않는 것(기기 안 처리).

## 결정
- 사용자가 유튜브 공식 페이지를 별도 탭에서 직접 재생한다.
- HumScore는 `getDisplayMedia`(탭 오디오)로 기기 안에서만 변환한다.
- 오디오 저장·서버 전송 없음. 음표 숫자만 남긴다.
- 유튜브 임베드·API로 오디오를 추출하지 않는다.

## 대안과 기각
| 대안 | 기각 이유 |
|---|---|
| 서버에서 영상 다운로드 후 변환 | 유튜브 약관 위반 가능성, 저작물 서버 보관, 서버 비용, 기기 안 처리 원칙 훼손 |
| IFrame 임베드를 캡처해 변환 | API 정책의 오디오·비디오 분리 금지 조항에 걸릴 가능성(해석 미확인), 임베드 오디오 접근 수단 없음 |

## 결과·위험
- 혼합 음원(보컬+반주)에서 단선율 추출 정확도 한계. 2단계로 `@spotify/basic-pitch` 브라우저 실행 검토(라이선스 확인 필요, `secscan license`).
- 지원 브라우저: 데스크톱 Chrome·Edge(탭 오디오 공유 지원). Firefox·Safari와 모바일 브라우저는 탭 오디오 공유 미지원 또는 불확실 → `미확인`, 구현 전 실측 필요. 미지원 시 Y02에서 안내.
- Capacitor 앱 WebView의 `getDisplayMedia` 지원은 `미확인`.
- 사용자가 재생한 영상의 저작권 책임·약관 적합성은 공개 전 법률 검토 필요. 검토 전에는 비공개 베타로 제한.
