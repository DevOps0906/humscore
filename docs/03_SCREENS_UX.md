## 비고 (불필요 판단)
- C01 필터: 예배일 기간 필터 추가(예배일 내림차순 목록이라 지난 콘티 찾기에 필요).
- S02 탭: 불필요(공유 설정은 구역 1개, 탭·사이드 메뉴 없음). 저장 버튼만 추가(만료일 변경 저장용). 🔴 "구역" 1건은 이 이유로 유지.
- Y02 단계별 입력: 불필요(탭 공유 선택은 브라우저 대화상자가 맡고 앱 입력란 없음). 입력란 신설은 기능 추가라 팀장 결정. 🔴 1건 유지.
- E02: task-002 명세(`docs/specs/task-002-perform-boost.md`#4)의 `perform(보강)` 행을 이 문서 E02로 정리. 그 문서의 옛 행은 ID만 E02로 바꾸거나 표를 지워야 🔴이 사라진다(이 작업 범위 밖).

- 데이터 칸은 05_DATA_MODEL 표 이름만 쓴다. 기기 저장·읽기 전용 구분은 이 비고로: R01·K01은 로컬 저장 후 로그인 시 `scores` 동기화, E02는 `scores` 읽기만, Y02는 오디오를 저장하지 않아 `—`.
- 권장(임시 저장) Y01·R01·K01·C02: 불필요 — 입력 항목이 적고 한 화면에서 끝나 중간 저장할 분량이 없다(C02는 저장 버튼이 곧 저장). Y02 이어하기: 불필요 — 탭 캡처는 세션 중에만 가능해 이어할 수 없다.
- 권장(관련 항목 탭·활동 이력) Y03·P01·S01·E01·E02·C03·C04: 불필요 — 한 악보/콘티 단일 목적 화면이며 버전 이력 기능은 현재 없음(신설은 팀장 결정).
- 권장(일괄 작업·저장된 보기) B01·C01: 이후 — MVP는 악보·콘티 수가 적어 개별 작업으로 충분. 필요 시 팀장 결정.
- 권장(근거·가격·FAQ) PR01 근거: 실제 후기·수치 확보 전까지 비움(가짜 수치 금지). W01 가격·FAQ: 가격은 PR01·FAQ는 L01이 맡아 중복 안 함.

## 팀장 결정 필요
- 후기·사용자 수는 실제 수치 확보 전까지 `미확인`(가짜 수치 금지).
- Y01 경로·로그인 필수 여부(가입 없이 시작 원칙과 충돌 가능).
- Pro 가격(07#5 제안 월 4,900~6,900원은 미확인 근거).
