# task-002 공연 모드 보강 — 기능 명세

> 표기: **[확인]** = 코드·문서에서 직접 확인 / **[추정]** = 확인 전 추정 / **[미확인]** = 근거 필요. 10장 결정 전 수치는 초안.

## 1. 목적·범위
공연 모드에서 저장한 악보를 **느리게·부분만·현재 음을 보며** 들을 수 있게 해 연습에 쓰게 한다.
- 근거: `06_BENCHMARK.md` 3.2(44행)·3.3(48행) — "재생 속도 조절·현재 음 강조 점검, 구간 반복은 연습 필수로 보임". 같은 기능이 상세 화면 연습 바로 기획됨(`03_SCREENS_UX.md` P01).
- 현재 공연 모드 [확인] (`perform-client.tsx`): 큰 악보·확대(A−/A+, 0.8~2.6)·페달/탭 스크롤·전조(`TransposeBar`)·따라 치기(`FollowPanel`). **재생 기능은 없음** — 재생은 상세 화면(`score-client.tsx` `togglePlay` → `playScore`)에만 있다.

| 포함 | 제외 |
|---|---|
| ① 재생 속도 50~100% (원래 `bpm` 대비 배율) | 콘티 공연 모드(C04) |
| ② 구간 반복 A–B (마디 단위, 시작·끝 마디 지정) | 따라 치기·페달·전조·확대 재작성 (기존 그대로 둠) |
| ③ 재생 중 현재 음 강조(커서) + 화면 밖이면 자동 스크롤 | 100% 초과 속도, 박 단위·음 단위 구간, 악보 탭으로 구간 지정 |
| 재생·일시정지·처음으로 | 메트로놈·카운트인, 녹음, 상세 화면(P01) 연결(10장 #8) |

## 2. 사용자 흐름
| 단계 | 동작 | 비고 |
|---|---|---|
| 진입 | 악보 상세 → 공연 모드 (기존 경로) | 연습 바 기본 닫힘/열림은 반응형 표(4장) |
| 속도 | 50~100% 중 선택, 기본 100% | 재생 중 바꾸면 현재 위치에서 새 속도로 이어 재생 |

## 3. 기능 규칙
| 항목 | 규칙(초안) | 상태 |
|---|---|---|
| 속도 | 실제 박 길이 = `60 / (score.bpm × rate)`, rate ∈ [0.5, 1.0]. 단계는 10장 #1 | 합성음(`playInstrumentNote`) 일정 조정이라 음높이 변화 없음 [확인: 오디오 파일 재생 아님] |
| 표시 | "속도 70% · ♩=63"처럼 배율과 실제 템포를 함께 표시 | 원래 `bpm` [확인] `types.ts` |
| 구간 단위 | 원본 악보의 마디 번호(화면에 보이는 번호) 1..N | 마디 수는 `scoreMeasureCount` [확인: `form.ts`에서 사용] |
| 구간 안 도돌이표 | 권고: A→B를 한 번 쭉(구간 안 도돌이·D.C. 무시) | 10장 #2 |
| 구간 밖 재생(반복 꺼짐) | 기존과 같이 도돌이표 펼친 순서(`unrollScore`·`measureOrder`) | [확인] `playScore`가 `unrollScore` 사용 |
| 코드 반주 | 기존 `playScore` 기본(코드 포함) 유지. 구간 첫 박에 코드가 없으면 직전 코드 적용 | `unrollScore`의 "건너뛰어 들어온 마디" 규칙과 같게 [확인] |
| 구간 끝 음 | B 마디 끝을 넘는 음 길이는 B 끝에서 자름 | |
| 셈여림·전조 | 기존과 같게 `velocityAt`·`transpose` 적용 | [확인] `playScore` |
| 반복 이음 | 다음 회차를 현재 회차 끝 직전에 미리 예약(끊김 없이). 예약 여유는 실측 | [추정] 탭 비활성 시 타이머 지연(R1) |
| 일시정지·재개 | Web Audio 예약 음은 멈출 수 없음 → 정지 후 멈춘 박 위치 기억, 재개 시 그 박 이후 음만 다시 예약 | [확인] `Playback.stop`은 버스 감쇠·해제만 |
| 커서 | `ctx.currentTime`에서 현재 박 계산 → 시작 박 ≤ 현재 박인 마지막 음의 **원본** `score.notes` 인덱스를 `ScoreView` `cursor.selected`로 전달. 바뀔 때만 상태 갱신 | 따라 치기가 같은 방식으로 `ScoreCursorProps` 재사용 중 [확인]. 펼친 음 → 원본 인덱스 매핑은 `buildFollowPlan.noteIndexes`와 같은 방식 [확인: `follow.ts`] |
| 화음 | 같은 시작 박 여러 음이면 맨 위 음에 커서 | `buildFollowPlan`과 같은 규칙 |
| 쉼표 | 쉼표 동안 커서는 쉼표 음표에 둔다 | `midi === null` = 쉼표 [확인] |
| 자동 스크롤 | 커서가 화면 밖으로 나갈 때만 스크롤 | `ScoreView`가 `selected` 변경 시 `scrollIntoView({block:"nearest"})` [확인]. 페달 수동 넘김과 충돌 R3 |
| 키보드 | 페달 키(←/→, PageUp/Down, Space)는 기존 페이지 넘김 유지, 재생 단축키 없음 | 10장 #9 |

## 4. 화면 배치 (`03_SCREENS_UX.md` 표 형식, 기존 perform 화면 보강)
| ID | 화면 | 유형 | 경로 | 주된 일 | 구성 | 데이터 | API | 권한 | 다음 |
|---|---|---|---|---|---|---|---|---|---|
| perform(보강) | 공연 모드 + 연습 바 | 상세 | /scores/[id]/perform | 느리게·구간 반복으로 듣고 연습 | header(닫기·제목·따라 치기·A−/A+), card:악보(재생 커서), toolbar:연습 바(button:재생·일시정지, button:처음으로, form:속도 50~100%, form:구간 시작·구간 끝, button:반복 켜기), 기존 TransposeBar, aside:따라 치기(켜졌을 때) | scores(읽기) | 없음(로컬) | 기존 perform과 같음 | scores/[id] |

| 상태 | 화면 |
|---|---|
| 비어 있음 | 음표 0개(또는 모두 쉼표) → 연습 바 비활성 + "음표가 없어 재생할 수 없어요" |
| 대기(정지) | 재생 버튼 활성, 커서 없음 |
| 준비 | 오디오 시작 대기(제스처 후 `statechange` 대기, 상세 화면과 같이 최대 3초 [확인]) → "소리 준비 중…" |
| 재생 | 일시정지 버튼, 커서 이동, 속도 표시 |
| 반복 중 | 재생 + "반복 A–B 마디" 배지(색+텍스트), 회차 표시 없음 |
| 일시정지 | 재생 버튼, 커서 멈춘 음에 유지 |
| 오류 | 오디오 시작 실패(3초 초과) → "소리를 켜지 못했어요. 다시 눌러 주세요" + 대기로 복귀 |
| 비활성(따라 치기 중) | 연습 바 회색 + "따라 치기 중에는 재생할 수 없어요" |

| 구간 | 배치 (따라 치기 패널과 공존) |
|---|---|
| 모바일 ~767 | 하단 패널에 한 줄 연습 바(재생·처음으로·속도). 구간은 접이식(P01과 같게). 전조 바는 그 아래. 따라 치기 켜지면 연습 바 자리에 FollowPanel(기존 `max-height:480px` 숨김 규칙 유지) |
| 태블릿 768~1199 | 하단 패널에 연습 바 전체(속도·구간 펼침) + 전조 바. 따라 치기 켜지면 모바일과 같이 연습 바 자리에 FollowPanel(비활성 연습 바 숨김 — 리뷰 반영, 팀장 결정 2026-10-29) |
| 데스크톱 1200~ | 권고: 악보 아래 행(현재 전조 바 행, `lg:row-start-3`)에 연습 바 + 전조 바 가로 배치. 우측 `lg:w-96` 패널은 따라 치기 전용 유지 (10장 #3, P01 "악보 옆 고정 패널"과 다름) |
| 공통 | 색·크기·폰트는 `globals.css` `@theme` 토큰만, 터치 영역 기존 버튼 크기(`h-11`/`size-11`) 유지, 속도·구간 값은 `aria-live`로 안내, 반복 배지는 색만으로 구분 금지 |

## 5. 공유 설계 (P01과 공용)
| 단위 | 위치 | 역할 | P01 재사용 |

## 6. 데이터
- **`Score` 영향 없음**: `types.ts` 변경 없음, 저장 데이터 변경 없음. 속도·구간·반복 여부는 화면 상태(권고, 10장 #5).
- 로컬 저장을 택하면: 키 `humscore:practice:<scoreId>`, 값 `{rate, a, b, loop}`만. 읽을 때 범위 검증·보정(`keys-draft.ts`처럼 손상 시 폐기). 서버 동기화 없음.
- 오디오 데이터 생성·저장·전송 없음(재생만). 새 의존성·노출 면·키 없음 → 보안 레벨 변화 없음(`01_PRD.md#8`). 새 노출 면이 없어 위협 메모 표 불필요.
